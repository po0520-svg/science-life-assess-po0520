# 生命探索站

國中自然互動課程：生命現象、細胞、物質交換、組成層次與大小世界。

網站：https://po0520-svg.github.io/science-life-assess-po0520/

## 操作與紀錄

填寫班級、座號、姓名後開始。共 10 頁，含 13 張複式顯微鏡閃卡、25 題學習題、10 題理解檢查、6 關救援與 20 題極限挑戰。學習題重答按 3、2、1 分計算；理解檢查保留首次結果，遊戲保留首次與最高結果。初版開放自由導覽。

學生進度保存在目前瀏覽器。切換身分會重新開始；尚未送出的紀錄持續保留於裝置，連線後可在成果頁「再次同步」。收件成功後才移除待送紀錄。排行榜只提供匿名代稱，不公開班級、座號或姓名。

## GAS 新建設定

1. 在 https://script.google.com/ 新建專案。
2. 將 `gas/Code.gs`、`gas/AnswerKeys.gs` 分別貼入同名程式檔；專案時區設為台北。
3. 執行 `setup`，完成 Google 授權。程式會新建私人「生命探索學習回應總表」，執行記錄顯示試算表網址。再次執行沿用同一份表。
4. 「部署 → 新增部署作業 → 網頁應用程式」，以自己身分執行，存取對象設為「所有人」。試算表本身維持私人。
5. 複製結尾 `/exec` 的部署網址，填入 `config.js` 的 `gasUrl`，提交至 GitHub。網址不得使用 `/dev`。
6. 在正式網站使用測試身分完成一題，確認「回應紀錄」與「學習總表」出現紀錄，再確認成果頁無待送資料。

教師直接從私人試算表查看回應。公開端點只提供收件與匿名排行榜，不提供學生紀錄查詢。收件端再次依答案表計分；遊戲時間來自學生裝置，本課程適合形成性學習紀錄。

更新 GAS 程式後，需在「管理部署作業」選新版本；修改題目後先執行 `node tools/build-keys.cjs`。

## 本機與發布

直接開啟 `index.html` 可預覽；建議以靜態伺服器測試。沒有建置依賴。

```sh
node tools/build-keys.cjs
node tests/core.cjs
```

GitHub Actions 將網站檔與 `assets` 發布至 Pages。原始 PDF、DOCX、草圖及試算表不發布。
